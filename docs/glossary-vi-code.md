# Glossary Việt – code

| Thuật ngữ nghiệp vụ | Code/schema |
|---|---|
| Tổ chức / không gian làm việc | `organization_id`, workspace |
| Kế hoạch lựa chọn nhà thầu | `ke_hoach_lcnt`, `kehoach` |
| Gói thầu | `goi_thau`, `goithau`, package |
| Hồ sơ dự thầu / thông tin mở thầu | `thong_tin_mo_thau`, bid/opening |
| Phần lô | `goi_thau_phan_lo`, `lotScope` |
| Danh mục hàng hóa yêu cầu | `goi_thau_hang_hoa` |
| Hàng hóa dự thầu | `hang_hoa_du_thau_nha_thau` |
| Vòng đánh giá | `vong_danh_gia`, `evaluationRoundId` |
| Báo cáo đánh giá | `bao_cao_danh_gia_nha_thau` |
| Nhà thầu / liên danh | `nha_thau`, joint venture |
| Chuyên gia | `chuyen_gia` |
| Phân công nhân sự | `phan_cong_nhan_su`, assignment |
| Bản ghi đã xóa | tombstone, `deleted_records` |
| Phiên bản đồng bộ | `sync_version`, `throughVersion` |
| Phiên bản dòng | `row_version`, `expectedVersion` |
| Khôi phục | explicit restore command |
| Bằng chứng audit bất biến | immutable audit evidence |
| Lịch sử hiển thị | activity feed/timeline |
