# Chỉ quản lý trạng thái hợp đồng

“Trạng thái hồ sơ giấy” đã được loại bỏ và không cần bảo toàn hoặc khôi phục vì “Trạng thái hợp đồng” là trạng thái nghiệp vụ duy nhất còn được sử dụng. Các thay đổi sau không được tái tạo cơ chế trạng thái hồ sơ giấy như một nguồn trạng thái song song.
