## Meaningful Product Action chính thức

Một meaningful action là action server-authoritative hoặc feature allowlist phản ánh công việc thật, không phải presence. First Value v1 dùng action thành công mạnh nhất hiện có: tạo gói thầu, tạo hợp đồng, commit source snapshot có consume, hoặc hoàn tất export Word. Khi thêm `planning.create/import` success seam chính thức, definition được version bằng ADR thay vì sửa lịch sử.
