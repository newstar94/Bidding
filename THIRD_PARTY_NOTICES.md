## Animate UI (design reference)

The presentation motion layer (`views/css/motion.css`,
`frontend/shared/motionEnhancements.js`) re-implements interaction patterns
from Animate UI (https://animate-ui.com) in plain CSS/JavaScript: sliding tab
indicator, ripple button, dialog/dropdown spring entry and counting numbers.
No Animate UI source code, React components or packages are bundled.
